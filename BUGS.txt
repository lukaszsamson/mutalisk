Mutalisk consolidated bug triage
================================

Updated 2026-10-01 against HEAD 6f20798 and the current working tree.
Sources: BUGS_CLAUDE.txt, BUGS_GPT.txt, BUGS_GROK.txt, BUGS_OX.txt,
BUGS_DEEP.txt, BUGS_KIMI.txt, BUGS_ASTRA.txt. BUGS_TRIAGED.txt is the
historical implementation log; this file is the current consolidated queue.

FIXED means the implementation and regression coverage are present.
OPEN means a remaining defect has been reproduced. REJECTED means the
reported claim is invalid. Repeated reports share one entry; original B1-B42
numbers are retained. 

The full quality gate is bash bin/verify. Each new bug fix gets its own commit.

Original consolidated findings
------------------------------

B01 [FIXED] Invalid UTF-8 in child output can destroy the final JSON report
    Captured child output is scrubbed to valid UTF-8; report writes fail cleanly.

B02 [FIXED] Sandbox reuse preserves test-written priv/ state across mutants
    Reset restores priv files, directories, and symlinks between mutants.

B03 [FIXED] The per-test timeout is also used as the whole-suite host deadline
    Suite deadlines use baseline duration or an explicit --suite-timeout-ms budget.

B04 [FIXED] OTP app names are conflated with umbrella directory basenames
    Directory-to-OTP-app mapping is used for manifests, beams, and sandbox tracking.

B05 [FIXED] Incremental history ignores umbrella children under custom :apps_path
    Child globs use the configured apps_path.

B06 [FIXED] Incremental digests AST-normalize .eex/.heex templates
    Only .ex/.exs inputs are AST-normalized; templates are hashed byte-for-byte.

B07 [FIXED] --enable does not gate dispatch mutants and cannot activate some targets alone
    Dispatch is target-gated; leaf targets activate their required parent.

B08 [FIXED] Umbrella schema rollback cannot match app-relative compiler diagnostics
    Rollback resolves child-relative diagnostics against placement aliases.

B09 [FIXED] Any non-app entry under apps/ can abort umbrella overlay installation
    Only child directories containing a Mix project are selected.

B10 [FIXED] FloatLiteral preserves the original :token and emits no-op mutants
    Replacement literals omit the original token metadata.

B11 [FIXED] ClauseDelete reorders try sections into unparseable syntax
    Try sections are replaced in place without changing keyword order.

B12 [FIXED] Multi-line module attributes can receive inverted source spans
    Span end offsets use both end line and column and reject inverted spans.

B13 [FIXED] Ordinary setup errors crash as raw MatchErrors
    Setup errors are handled explicitly; allocated resources are cleaned up.

B14 [FIXED] Partial sandbox-pool creation leaks previously created sandboxes
    Partial pools are removed before returning creation errors.

B15 [FIXED] EnvWalker treats all remote/dot calls as leaves
    Remote receivers and call arguments are traversed.

B16 [FIXED] Trusted if/unless branches are not descended by EnvWalker
    Keyword values and branch bodies are traversed.

B17 [FIXED] StringLiteral renders the "x" heredoc replacement as invalid Elixir
    Replacement strings omit heredoc delimiter metadata.

B18 [FIXED] Nested-module EnvWalker mutants bypass @mutalisk_ignore
    Relative module aliases resolve against the enclosing module.

B19 [FIXED] Pin and opt-in walkers traverse quote/code-generation subtrees
    All relevant walkers honor quote/code-generation refusal.

B20 [FIXED] Membership mishandles x not in y
    Membership suppresses the inner candidate of not-in; UnaryNot handles reversal.

B21 [FIXED] UnaryNot and GuardBoolean can render byte-identical fallback mutations
    Rendered identity patches are rejected, including after schema rerouting.

B22 [FIXED] StatementDelete does not hazard-gate alias/import/require
    Lexical directives are treated as deletion hazards.

B23 [FIXED] AttributeLiteral emits identity mutants for 0 and 0.0
    Equal and duplicate attribute replacements are filtered.

B24 [FIXED] --test-paths is documented as a CLI option but is rejected
    --test-paths is supported as a repeatable path-list option.

B25 [FIXED] Stryker JSON uses incompatible killedBy and coveredBy test IDs
    File-level killedBy/coveredBy IDs share the emitted testFiles namespace.

B26 [FIXED] Disabled schema-literal candidates vanish without skip records
    Disabled literal candidates produce skip records.

B27 [FIXED] Incremental progress can never reach its displayed denominator
    Progress accounts for reused verdicts.

B28 [FIXED] An all-skipped selected suite is classified Survived
    Only passed and failed tests count as having run.

B29 [FIXED] app_from_ast accepts the first app: pair anywhere in mix.exs
    Project app lookup reads the project keyword list before using fallbacks.

B30 [FIXED] WorkCopy.materialize leaks a completed copy on post-copy failure
    All non-ok post-copy results remove the work copy.

B31 [FIXED] Timed-out ports leave stale messages in long-lived mailboxes
    Closed-port data and exit messages are drained.

B32 [FIXED] ProcessTree skips descendant cleanup if the wrapper port already closed
    Process-group cleanup and verified descendant cleanup cover exited wrappers.

B33 [FIXED] Coverage resolves relative test paths against host cwd before the work copy
    Relative test paths resolve against the work-copy root.

B34 [FIXED] FunctionReplace can violate import ..., only: for bare calls
    Replacement bare calls honor the current import scope.

B35 [REJECTED] Sequential execution does not thread sandbox-pool state
    The sequential reduce already threaded pool state; the reported loss is invalid.

B36 [FIXED] Duplicate CLI detection misses dash/underscore spelling mixes
    Duplicate flag checks normalize names; repeatable test-path handling is explicit.

B37 [FIXED] A missing CLI option value is reported as an unknown option
    Missing option values get an actionable diagnostic.

B38 [FIXED] The pathological-coverage abort message mislabels its ratio
    The displayed ratio and threshold are labeled consistently.

B39 [FIXED] The e2e score helper divides by zero when no mutant is scored
    Empty score denominators are guarded.

B40 [FIXED] mix mut docs omit the legacy config :mut precedence layer
    Help documents both config namespaces and their precedence.

B41 [FIXED] collection_span lacks the nil start-byte guard used by sibling helpers
    Nil source offsets degrade to a missing-span result.

B42 [FIXED] A failed threshold run still prints a success-style completion banner
    Failed gates and report writes produce a failure banner.

Rejected additional claims
--------------------------

R01 [REJECTED] Kernel.update_in(state.recompile_categories[cat], ...) returns a scalar.
    The path-form macro returns the whole state; its updater already handles nil.
R02 [REJECTED] BEAM-startup retries append duplicate schema clauses.
    Instrumentation occurs once; retries compile the same source and overwrite
    beams. Startup-transient signatures precede compilation (T35).
R03 [REJECTED] Including NoCoverage in the score denominator is a scoring bug.
    This is the documented status model; only the stale worker comment was wrong.

Previously checked and cleared
------------------------------

C1. Empty cross-app test-file lists under custom apps_path do not drop tests

    An empty files: [] argument causes mix test to run the full suite. It may be
    slower, but it does not create false NoCoverage results.

C2. Mutation-score arithmetic matches the documented status model

    Metrics and terminal percentage divisions are zero-guarded. Killed and Timeout
    are detected; Survived and NoCoverage are undetected. A Worker comment claiming
    NoCoverage is excluded is stale, but the implemented score is consistent.

C3. operator_token_span uses character-compatible splitting

    String.split_at/2 operates consistently with parser columns here. The separate
    byte-based rendered_span path already handles its actual byte/character issue.

C4. @mutalisk_ignore itself becoming an AttributeLiteral candidate is harmless

    apply_module_ignores drops every mutant in the marked module, including a
    candidate derived from the ignore attribute itself.

C5. The pipeline-pruning sentinel is inert during traversal

    Macro.traverse does not recurse into the accumulator map stored by the sentinel,
    so the unusual representation does not leak candidates.

C6. Dispatch candidates under guards are deduplicated

    The :when element-path rejection prevents dispatch and guard walkers from
    emitting the same mutation twice.

C7. Enum.min_by/3 uses an empty fallback on the supported Elixir version

    On Elixir 1.19 and later, the zero-arity third argument is the empty fallback,
    not a sorter. The current call is valid for the project's version requirement.

C8. History garbage collection honors its retention bound

    The generation slicing logic keeps exactly the configured retention count.

C9. Digest truncation, normalization fallback, and tie-breaking fail safely

    The investigated paths over-invalidate history rather than unsafely reusing a
    stale result. This does not clear the two specific digest findings above.

C10. Output truncation arithmetic and marker accounting are consistent

     bounded_output/trim_output preserve their intended byte budget. The separate invalid-output bug is fixed (B1).

C11. Stryker JSON temporary-file replacement is safe on its intended path

     The temporary file is created in the destination directory, so the normal
     rename is atomic; the EXDEV fallback is defensive rather than routinely used.

C12. Multi-variant mutators receive distinct stable IDs

     Sorted mutation metadata is incorporated into stable_id_kind, distinguishing
     variants of the same source candidate.

C13. !== and === operator spans round-trip correctly

     Macro.to_string plus the operator-prefix span check sizes these operators
     correctly; the suspected corruption was not reproduced.

C14. mix test --timeout is passed in the correct unit

     ExUnit expects milliseconds and receives milliseconds. This does not clear
     finding 3, which concerns applying the per-test value to the entire host suite.

C15. Exclude polarity and regex flags are preserved

     Per-pattern exclusion behavior and regex option propagation were checked and
     found correct.

C16. Debug-plan invalid count being zero is cosmetic, not a verdict bug

     The suspicion was too weak to promote to a finding without a user-visible
     correctness impact.

C17. Fractional --fail-at comparisons need stronger evidence

     A possible mismatch involving unusual thresholds such as 80.04 was noted, but
     not established as a reportable bug.

C18. Unreadable covering tests in history need a concrete failure scenario

     The suspected omission would require the file to be missing or unreadable both
     when history is written and when it is reused; no supported scenario was shown.
